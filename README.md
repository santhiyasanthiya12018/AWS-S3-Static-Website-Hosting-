# AWS-S3-Static-Website-Hosting-

*AWS S3 Static Website Posting:*

This project demonstrates how to host a fully functional static website using Amazon S3. The implementation shows how AWS S3 can be used as a highly available, scalable, and cost-effective hosting solution for static web applications such as portfolio websites, landing pages, and business websites.

The project includes configuring an S3 bucket for static website hosting, enabling public access policies, uploading website files, and configuring permissions for secure public website access. This solution provides reliable hosting with minimal operational overhead.

*Key Feature:*

•	Static website hosting using Amazon S3.
 
•	High availability and saal agility.
 
•	Cost-effective serverless hosting solution.
 
•	Public access configuration for web content deliver.
 
•	Bucket policy management for secure access controller.
 
•	Fast deployment with minimal infrastructure Set Up.
 
•	Supports HTML, CSS, JavaScript, and media files.

 
*AWS Services Use:*

•	Amazon S3
 
•	Bucket policies
 
•	Static Website Hosting Configuration.
 
•	IAM Permission.
 
•	AWS Management Console.
 
*Architecture Work flow:*

1.	Create an Amazon S3 bucket 

2.	Enable static website Hosting
 
3.	Upload website files (HTML, CSS, JS)
 
4.	Configure public access settings
 
5.	Apply bucket policy for public read access 

6.	Access website through generated endpoint URL
 
7.	Verify website availability and performances
 
*Security Benefit:*

Access permissions are controlled through bucket policies and IAM configurations, ensuring secure management of hosted content while allowing public read access only where required.
